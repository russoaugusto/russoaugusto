# Augusto Russo | Dados, planejamento e segurança de dados

Meu portfólio reúne estudos de análise de dados aplicados ao planejamento de operações, com foco em capacidade, filas e qualidade de indicadores.

> **Portfólio demonstrativo.** Os dados e resultados dos estudos são fictícios.

**[Portfólio de Dados Operacionais](https://github.com/russoaugusto/portfolio-dados-operacionais)** · **[Painel interativo](https://russoaugusto.github.io/portfolio-dados-operacionais/)** · **[Matriz de competências](https://github.com/russoaugusto/portfolio-dados-operacionais/blob/main/docs/competencias.md)**

## Estudos em destaque

- [Capacidade e fila](https://github.com/russoaugusto/portfolio-dados-operacionais/blob/main/docs/cases/capacidade.md). Simulação do saldo diário da fila em função da demanda e da capacidade.
- [Granularidade e `JOIN`](https://github.com/russoaugusto/portfolio-dados-operacionais/blob/main/docs/cases/granularidade.md). Validação da cardinalidade das junções para evitar contagens duplicadas.
- [Comparação por horário de corte](https://github.com/russoaugusto/portfolio-dados-operacionais/blob/main/docs/cases/horario-de-corte.md). Análise de volumes em janelas equivalentes para comparar dias.
- [Matriz de permissões e menor privilégio](https://github.com/russoaugusto/portfolio-dados-operacionais/blob/main/docs/cases/acessos-fora-do-perfil.md). Revisão simulada de acessos por perfil, com documentação e código no GitHub e estreia no painel prevista para 1º de dezembro de 2026.

## Competências demonstradas

- Consultas analíticas em **SQL (SQLite)**, incluindo CTEs, junções e validação de indicadores.
- Geração de dados sintéticos e testes automatizados em **Python**, com **GitHub Actions** para validar as mudanças.
- Revisão de permissões e verificações estáticas para sinalizar **possíveis credenciais expostas** no código.
- Visualização de indicadores de **BI** em um painel feito com **JavaScript, HTML e CSS**, publicado no GitHub Pages.

As [instruções de reprodução](https://github.com/russoaugusto/portfolio-dados-operacionais#executar-e-validar) mostram como executar os testes e abrir o painel localmente.
